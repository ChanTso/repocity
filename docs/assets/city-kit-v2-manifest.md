# City Kit v2 asset manifest

All assets below are deterministic original geometry generated by `scripts/generate-city-kit-v2.mjs` from the single canonical source `app/lib/chicago-kit-v2-definition.json`. They are licensed with RepoCity under Apache-2.0 and contain no marketplace models, copied landmarks, third-party textures, game screenshots, logos, or trademarked signage.

The GLBs are inspectable tooling/reference module catalogs. Runtime rendering intentionally compiles instanced geometry from the same canonical recipes. `catalog.json` records the explicit purpose `tooling-reference-runtime-procedural-parity`, exact named root maps, definition fingerprints, recipe fingerprints, byte sizes, triangle counts, and SHA-256 hashes. Automated tests require runtime/catalog parity, so these assets are neither an unused second implementation nor an unaudited runtime dependency.

Every GLB contains two family-named base roots, three family-named rhythm roots, two family-named corner roots, three family-named roof roots, plus `end-wall-exposed`, `end-wall-party`, and `rear-service`. The exact mapping is recorded per family rather than relying on positional names such as `corner-1`.
