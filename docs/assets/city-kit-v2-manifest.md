# City Kit v2 asset manifest

All assets below are deterministic original geometry generated by `scripts/generate-city-kit-v2.mjs`. They are licensed with RepoCity under Apache-2.0 and contain no marketplace models, copied landmarks, third-party textures, game screenshots, logos, or trademarked signage.

Generator inputs contain no clock or random state. Two consecutive generation runs produced identical byte hashes. The runtime uses a matching instanced-module compiler; these GLBs are the canonical inspectable module catalogs and remain available for tooling and future loaders.

Every GLB contains these roots: `base`, `middle-rhythm-1`, `middle-rhythm-2`, `middle-rhythm-3`, `corner-1`, `corner-2`, `end-wall`, `setback-shoulder`, `roof-1`, `roof-2`, and `roof-3`.
